## How This Vault Works

Information gradually moves through:

```text
capture → organize → connect → refine → revisit
```

Some pages are polished reference notes, while others remain active working notes.

The vault is intentionally iterative: knowledge is expected to change as my understanding improves.

## About

Vault V2 is built with Markdown and published using Quartz.

The project also serves as an experiment in structured knowledge management and AI-assisted note organization.
